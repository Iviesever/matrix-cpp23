# 矩阵计算器 (Matrix Calculator)

**By lviesever**

这是一款使用现代 C++23 和 Qt 6 开发的图形化矩阵计算器。它提供了一系列丰富的矩阵运算功能，从基础的加减乘除到高级的求逆、求特征值以及求解线性方程组，旨在为学习和研究线性代数提供便利。

![screenshot](./.images/screenshot.png)

## 功能特性

本项目实现了对矩阵的多种核心运算：

#### 数据类型

- 支持 2 种计算类型，浮点数 (double) 、实数 (rational)，可在界面左上角切换。

#### 基础矩阵运算

- **矩阵加法** (A + B)
- **矩阵减法** (A - B)
- **矩阵乘法** (A * B)

#### 高级矩阵运算

- **行列式** (det(A))
- **逆矩阵** (inv(A))
- **特征值** (lambda(A))
- **伴随矩阵** (adj(A))
- **矩阵的秩** (rank(A))
- **矩阵的迹** (trace(A))
- **行阶梯形矩阵** (ref(A))
- **简化行阶梯形矩阵** (rref(A))

#### 线性方程组求解

- 求解**齐次线性方程组** `Ax = 0`
- 求解**非齐次线性方程组** `Ax = b`

## 技术栈

- **核心语言**: C++23
- **GUI 框架**: Qt 6
- **开发环境**: Visual Studio 2026 Insiders

## 🚀 如何编译

### 依赖环境

1.  **C++23 编译器**: 本项目使用 Visual Studio 2026 Insiders 开发，建议使用 **Visual Studio 2026 Insiders 最新版本**。
2.  **Qt 开发环境**:  本项目依赖于一个**静态编译**的 Qt 6 库。这意味着您需要自行从源码编译 Qt 并配置 -static 选项，或者获取一个为您环境预编译好的静态版本。
3.  **Qt VS Tools**: 在 Visual Studio 的“扩展”菜单中，搜索并安装 `Qt Visual Studio Tools` 插件，并确保其正确配置了您的 Qt 安装路径。
